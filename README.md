# IDE SIGNAL

Formulaire public pour partager une idée de projet et recevoir un score d'opportunité (indicatif, sans IA).

## Stack

- React + Vite + Tailwind CSS v4
- Framer Motion + canvas-confetti
- Google Apps Script + Google Sheets (optionnel via env)
- Netlify

## Scripts

```bash
npm install
npm run dev
npm run build
```
